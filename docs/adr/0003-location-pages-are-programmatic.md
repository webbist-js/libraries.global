# Location pages are programmatic; CMS copy only overrides

Continent, Country and Region pages build their title, meta description, hero intro and structured data from Library data (counts, `libraryType` breakdown, featured Libraries). The CMS no longer has a `sections` dynamic zone on these types. What's left is an optional `seo` override on all three, and an optional `about` rich-text field on Continent and Country for real context, such as how a country organises its library systems. There are hundreds of Regions per country, and nobody can write copy for that many, so templated editorial blocks would only add thin, duplicated content. A Location with fewer than `MIN_INDEXABLE_LIBRARIES` published Libraries (`apps/ui/src/lib/seo/location.ts`) is served `noindex, follow` and left out of the sitemap, so a page gets into search results only once it has records. We considered hand-written copy on every Location page, and dropped it because it can't be done at that scale and adds no search value over accurate data.
