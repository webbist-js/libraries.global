## Notes / concerns

- Strapi was confirmed to be running current code before testing: `POST /api/content-moderation/uploads` without the secret returned 401 (not 404).
- A2, A3, A4, A8 and A11 genuinely require an admin JWT, a browser session, or the Next server, none of which are available in this environment; they're left as manual steps above rather than guessed at.
- A13 is the one scenario that fails its literal written acceptance criterion on a live check today. Task 14 treated the content-manager/MCP status overlay as an accepted, documented limitation rather than a fix (submissions still use Strapi's reserved `status` field, not a renamed `reviewStatus`). This is worth a human decision before treating P-A as fully closed.
