# Japan: National Diet Library ISIL registry

```sh
pnpm ingest --dataset=jp-ndl-isil
pnpm ingest --dataset=jp-ndl-isil --local --check-cms
pnpm ingest --dataset=jp-ndl-isil --local --apply --limit=5
pnpm ingest --dataset=jp-ndl-isil --release=20261102 --snapshot=scripts/ingests/japan/ndl-isil/.cache/20261102
```

Run from `apps/strapi`. The default maps the complete source without CMS access. CMS checks and writes require `--local` or `--production`. Existing `jp-ndl-isil` Source Records are skipped, so a rerun against the first import creates nothing new.

The [National Diet Library](https://www.ndl.go.jp/library/isil) states that its ISIL lists are public domain, including commercial reuse. File names carry the release date, so the adapter defaults to `--release=20261102`, the release the first import used. A newer release changes counts and needs review before it is imported. Each run reads three files:

- `isil_libraries_public_<release>_J.csv`: public libraries.
- `isil_libraries_<release>_J.csv`: other libraries and public reading rooms.
- `isil_deleted_<release>_J.csv`: withdrawn ISILs. A withdrawn ISIL still present in either list stops the run.

Museum and archive lists are not read. The two library lists label some columns differently, so columns are read by position after every heading is checked. The cache keeps the mapped columns and the SHA-256 of each downloaded file. The first import (7 November 2026) read 7,602 entries: 7,582 new Libraries, the curated National Diet Library and 19 held without a prefecture or municipality.

| Source column               | Library field                 | Rule                                                                                                                                                                                                                                                                                                                                                                                                              |
| --------------------------- | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ISIL                        | Source Record ID, slug suffix | Must match `JP-nnnnnnn`. Slug is the ASCII-folded English name (160 characters at most, `library` when empty) plus the lower-case ISIL, as published.                                                                                                                                                                                                                                                             |
| Japanese name               | `name`                        | Kept in Japanese.                                                                                                                                                                                                                                                                                                                                                                                                 |
| Kana, English name          | `alternateNames`              | Kana reading, then the English name unless it contains a run of 12 capitals (romanised kana rather than readable English).                                                                                                                                                                                                                                                                                        |
| List, Japanese/English name | `libraryType`                 | The three NDL buildings → National; NDL branch libraries → Special; public list → Regional for prefectural libraries, otherwise Public. Other list, by name: 議会 → Parliamentary; 点字, 視覚障害, ライトハウス → Specific User Groups; 大学 → University; vocational and technical colleges → Academic; research, corporate, foundation, ministry, museum, hospital and centre names → Special; otherwise Other. |
| Prefecture                  | Region                        | Explicit table of the 47 prefectures to existing Atlas names.                                                                                                                                                                                                                                                                                                                                                     |
| City/Ward/Town/Village      | `city`                        | Kept as published. No Area relation is inferred.                                                                                                                                                                                                                                                                                                                                                                  |
| Address, postal code        | `streetAddress`, `postalCode` | Address as published; postal code only in `nnn-nnnn` form.                                                                                                                                                                                                                                                                                                                                                        |
| Telephone                   | `phone`                       | Only digits, brackets, plus signs, hyphens and spaces (full- or half-width).                                                                                                                                                                                                                                                                                                                                      |
| URL                         | `website`                     | Only `http(s)://` without whitespace, 255 characters or fewer, unchanged.                                                                                                                                                                                                                                                                                                                                         |
| —                           | `operationalStatus`           | `unknown`. Registration does not establish visitor access or current operation.                                                                                                                                                                                                                                                                                                                                   |

No operators are inferred. Records without a prefecture or municipality are held, not guessed.

`JP-1000001` is the existing curated National Diet Library. With a CMS check, it is linked to `national-diet-library` when that Library's website is on `ndl.go.jp`, and is reported as existing. Otherwise it is skipped for editorial review rather than duplicated.

The first import also added pins from Geolonia/Digital Agency address and Ministry of Justice parcel points, and a later enrichment added municipal facility, Wikidata and dictionary-matched points. Each has its own Dataset and reference Source Records and needed manual review. This adapter creates Libraries without coordinates and does not reproduce those enrichments. Existing pins are untouched because existing Source Records are skipped.
