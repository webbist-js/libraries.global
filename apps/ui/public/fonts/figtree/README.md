# Figtree

Unmodified variable font from [Google Fonts](https://github.com/google/fonts/tree/a60a77e14f28abd4ef243a1b5dfc48df0cec5205/ofl/figtree), revision `a60a77e14f28abd4ef243a1b5dfc48df0cec5205`.

`Figtree[wght].ttf` is stored here as `Figtree-Variable.ttf`. It includes the Latin and Latin Extended glyphs and the 300–900 weight axis. The UI uses weights 400–700.

Copyright 2022 The Figtree Project Authors. Distributed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).

Bundling this font avoids the extensionless Google Fonts URL parsing failure in Next.js ([upstream issue](https://github.com/vercel/next.js/issues/99114)).
